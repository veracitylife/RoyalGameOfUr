# The Royal Game of Ur: Android APK Installer

Official Android APK installer for **The Royal Game of Ur** by **Clovis Star**.

The Royal Game of Ur is one of the oldest known board games in human history. This modern version brings the ancient Mesopotamian race game to Android with dice, rosettes, captures, strategy, and multiplayer play.
